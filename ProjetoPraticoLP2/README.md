## Tecnologias
- Java
- JSP
- Apache Tomcat
- Gson
- JSON
- HTML/CSS

## Persistência
Os dados serão armazenados em arquivos JSON dentro do próprio projeto. Não será utilizado banco de dados.

## Estrutura
- `src/`: classes Java
- `WebContent/`: páginas JSP e arquivos web
- `WebContent/dados/`: arquivos JSON
- `WebContent/includes/`: cabeçalho e rodapé reutilizáveis
- `WebContent/css/`: estilos
- `prints/`: evidências do projeto funcionando
- `apresentacao/`: materiais da apresentação

## Diagrama de classes
O diagrama será incluído após a definição das três entidades do projeto.

## Como rodar no Eclipse
1. Importe/abra o projeto no Eclipse.
2. Configure o Apache Tomcat como servidor do projeto.
3. Adicione o arquivo `.jar` da Gson ao Build Path e/ou a `WebContent/WEB-INF/lib`.
4. Execute o projeto no Tomcat.
5. Acesse a aplicação pelo endereço local exibido pelo servidor.
